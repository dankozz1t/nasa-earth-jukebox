This prototype uses the official public-facing NASA SVS 5669 visualization still and its accompanying colour bar:

- **GEOS Aerosols (2025)**, NASA Scientific Visualization Studio, ID 5669
- Frame timestamp: 19 August 2025, 20:00 UTC
- Model identified by NASA SVS: GEOS-FP 2Km Replay
- NASA SVS page: https://svs.gsfc.nasa.gov/5669/
- NASA visualization PNG: https://svs.gsfc.nasa.gov/vis/a000000/a005600/a005669/Aerosols_2025-08-19T20_00_00_1920x1080.png

NASA SVS states that its content is public domain unless otherwise noted. Users should retain this attribution and review NASA's media usage guidance for their intended redistribution/use:
https://svs.gsfc.nasa.gov/help/

This software does not contain the raw GEOS-FP model data. NASA's SVS page explicitly notes that it identifies the datasets used but does not host the datasets themselves. The extracted pixel masks and spatial profiles are derived from the visualization, not official numeric model products.
